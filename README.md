# Automatizaciones con n8n para pymes

Soy Carlos Solano, especialista en automatización con n8n e IA en Medellín, Colombia. Automatizo tareas administrativas y contables que hoy se hacen a mano: digitar facturas, cruzar pagos y revisar documentos.

| Proyecto | Qué resuelve | Tecnologías |
|---|---|---|
| [Lector de facturas electrónicas DIAN](lector-facturas-dian/) | Registra solas las facturas de proveedores que llegan al correo y alerta duplicados, proveedores nuevos y cobros atípicos | n8n, Gmail, Google Sheets, JavaScript |
| [Conciliación bancaria con IA](conciliacion-bancaria-ia/) | Lee facturas en PDF o foto y las cruza contra el extracto bancario | n8n, OpenAI GPT-4o, Google Drive, Google Sheets, Gmail |

Cada carpeta trae el flujo (`workflow.json`) listo para importar en n8n. No incluye credenciales ni datos reales.
